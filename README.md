Entry for the make.fun competition
[One-Sentence Absurd Invention Pitch](https://make.fun/bounty/u-suroso-69-one-sentence-absurd-invention-pitch-5326c34a):
one sentence pitching a ridiculous invention that fixes a tiny everyday
annoyance, at most 220 characters.

## The pitch (145 characters, verified)

> Introducing the Parachute Toaster: it ejects your toast under a tiny parachute, so it can never land butter-side down on the kitchen floor again.

The tiny annoyance is toast landing butter-side down (Murphy's law of the
breakfast table); the absurd fix is a toaster that launches every slice
under a miniature parachute.

## Run

```sh
node main.ts
```

`main.ts` (Node standard library only) writes the single sentence to
`/output/entry.txt`, or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when set. It
checks the gate first: one line, 1–220 characters, valid UTF-8, no
trailing newline.
